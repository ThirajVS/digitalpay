Security by design

Safe demonstrations, honest boundaries.

DigitalPay validates form input, uses prepared database statements and rejects private-network targets in the analyzer. It deliberately never asks for payment secrets.

  • Prepared statements for database operations
  • Server-side validation and output escaping
  • Restricted image uploads
  • SSRF-aware URL analysis

Never enter

  • Real card numbers or CVV
  • UPI PIN or OTP
  • Bank login credentials
  • Production API secrets
